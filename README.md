# 🎵 MusicMemoir

> Every feeling deserves a soundtrack.

MusicMemoir is a full-stack journaling web application that transforms journal entries into personalized musical experiences. Users can write about their day, receive an AI-generated reflection, and discover Spotify song recommendations based on the emotions expressed.

## ✨ Features

-  Write daily journal entries
-  AI-generated reflections using Google Gemini
-  Emotion-based Spotify song recommendations
-  Archive of previous memories
-  Login page UI

## 🛠️ Tech Stack

- HTML
- CSS
- Python
- Flask
- Google Gemini API
- Spotify Web API
- JSON

## 🚀 Getting Started

```bash
git clone https://github.com/Niyati0609/MusicMemoir.git
cd MusicMemoir
pip install -r requirements.txt
python app.py
```

Create a `.env` file with your API keys before running the application.
